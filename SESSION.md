### Operators inside DIC

1. **Non-destructive occupancy** — the object is already detected without being consumed (video, radar, remote sensing, a sequence fragment).

4. **Surrogate census fails** — no existing non-destructive method is already the literature's object for the *same* unknown.

- If more video / radar / remote sensing assigns the identity → Undersampling, not DIC.

- If the object recovers on observational timescales → not irreversible, not DIC.
- If the object was never seen non-destructively → Undersampling, not DIC.
